### SODS Protocol

Zero-cost cryptographic behavioral verification for decentralized networks.

SODS was designed to eliminate the need for heavy archive nodes when validating historical state behavior. Instead of forcing full-chain cost onto every verifier, it produces compact behavioral proofs that lightweight clients can validate efficiently.

- **Why it matters:** Trustless verification becomes practical for mobile, edge, and lightweight environments.
- **Stack:** `Rust` `Solidity` `libp2p` `RISC Zero`
